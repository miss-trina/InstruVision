# 🎵 InstruVision

An AI-powered musical instrument analyzer built with Streamlit and Google Gemini.

## 🚀 Live Demo

[🔗 Open InstruVision] ( https://instrumentanalyzer.streamlit.app/ )

## ✨ Features

- Upload an image of a musical instrument
- Identify the instrument using Gemini
- Detect instrument family
- Explain how it is played
- Identify visible parts and their functions
- Estimate learning difficulty
- Suggest related instruments
- Provide interesting facts

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini
- Pillow
